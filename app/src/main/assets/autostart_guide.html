📱 自启动权限设置教程

💡 开启自启动后，「V免签监控端_Pro」才能在后台稳定接收消息。
请根据您的手机品牌查看对应教程。

华为 / 荣耀

  1. 打开「手机管家」App
  2. 点击「应用启动管理」
  3. 找到「V免签监控端_Pro」，关闭右侧「自动管理」开关
  4. 在弹出窗口中勾选以下三项，然后点击「确定」：
    ☑ 允许自启动
    ☑ 允许关联启动
    ☑ 允许后台活动
⚠️ 三个选项必须全部勾选，缺少任一项后台仍可能被系统杀死。

小米 / 红米

  1. 打开「手机管家」App
  2. 点击「应用管理」→「权限」
  3. 点击「自启动管理」
  4. 找到「V免签监控端_Pro」，开启开关
⚠️ 建议同时开启「后台自启动」和「锁屏自启动」，防止锁屏后断连。

OPPO / 一加 / realme

  1. 打开「手机管家」App
  2. 点击「权限隐私」→「自启动管理」
  3. 找到「V免签监控端_Pro」，开启开关
⚠️ 如未找到自启动管理入口，也可尝试：
设置 → 电池 → 更多电池设置 → 优化电池使用 → 选择本应用 → 不限制
...

vivo / iQOO

  1. 打开「i管家」App
  2. 点击「应用管理」→「权限管理」
  3. 点击「自启动管理」
  4. 找到「V免签监控端_Pro」，开启开关
⚠️ 建议同时在「电池」→「后台耗电管理」中将本应用设为「允许后台运行」。
...

三星

  1. 打开「设置」
  2. 点击「电池和设备维护」→「电池」
  3. 点击「后台用量」
  4. 找到「V免签监控端_Pro」，选择「从不休眠」
⚠️ 如未找到，也可尝试：设置 → 应用程序 → V免签监控端_Pro → 电池 → 不限制
...

魅族

  1. 打开「手机管家」App
  2. 点击「权限管理」→「后台管理」
  3. 找到「V免签监控端_Pro」，选择「允许后台运行」
⚠️ 建议同时在「安全中心」→「自启动管理」中也开启本应用。
